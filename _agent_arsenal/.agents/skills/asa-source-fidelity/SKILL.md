# AsA Source Fidelity

The source is authoritative for what the user actually said.

Inventory every relevant source and record path, identity, hash, size, line/page count, completeness, and provenance.

For strategies build:
SOURCE → CONCEPT → STRATEGY → SETUP → RULE → SPEC → COMPILED RULE → VALIDATION

For each field classify COMPLETE / PARTIAL / UNKNOWN / CONFLICTING / NOT_PRESENT.

Never fill missing entry/stop/target/confirmation semantics from generic domain knowledge.

For psychology preserve concepts, definitions, states, triggers, behavioral patterns, decision constraints, recovery procedures, examples, exceptions, relationships, and terminology where supported.

Separate SOURCE-DERIVED / FORMALIZED / EXECUTABLE / NON-EXECUTABLE / UNKNOWN.

Every executable rule must trace back to source evidence.
A larger strategy count is not success; faithful coverage is success.
