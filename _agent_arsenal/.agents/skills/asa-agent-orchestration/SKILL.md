# AsA Agent Orchestration

Run one coherent large mission: classify → inspect → plan → implement → test → adversarial review → repair → runtime verify → diff review → deliver.

Do not create cosmetic patches merely to show progress. Do not stop at scaffolding.

Use parallel investigation only for independent read-heavy work; serialize writes to shared files or Git state.

Keep a compact working state: OBJECTIVE / CURRENT STATE / DECISIONS / DEPENDENCIES / BLOCKERS / VERIFIED EVIDENCE / NEXT ACTION.

Optimize for confirmed completion, steerability, bash recovery, and zero tool hallucination.
