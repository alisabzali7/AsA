# AsA Git Release

Before work inspect status, branch, recent commits, current diff, and relevant PRs.

During work keep commits focused and do not include secrets, credentials, node_modules, runtime databases, caches, or unrelated changes.

Before PR review the full diff, changed files, tests, build, runtime evidence, and limitations.

PR body should explain problem, implementation, source evidence, tests, runtime verification, blockers, and risks.

Plan around the fact that an Arena GitHub Agent Mode session currently supports one PR; keep one mission coherent and reviewable.
