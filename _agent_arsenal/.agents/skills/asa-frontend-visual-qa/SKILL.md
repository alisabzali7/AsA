# AsA Frontend Visual QA

Required loop:
DESIGN → IMPLEMENT → BUILD → RUN → OPEN IN BROWSER → INTERACT → INSPECT CONSOLE/NETWORK → FIX → RECHECK

AsA is an intelligence terminal, not a generic crypto dashboard.

Verify desktop/mobile, Persian/English, RTL/LTR, navigation, drawers, dialogs, tables, chart controls, keyboard flow, mixed Persian/Latin content, and all data states: LOADING / READY / EMPTY / UNAVAILABLE / STALE / PARTIAL / ERROR / OFFLINE.

The browser renders backend truth. Do not recreate authoritative indicators, strategy logic, psychology rules, risk decisions, or signal qualification.

Check semantics, focus, keyboard navigation, labels, dialogs, contrast, reduced motion, and touch targets.
